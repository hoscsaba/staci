Detailed Description

STACI examples

This directory contains user-facing examples. Automated regression and developer checks belong under tests/.

  • cpp/ demonstrates the native C++ API, EPANET INP import, and a direct official-EPANET-versus-STACI EPS comparison;
  • matlab/ demonstrates the in-memory MATLAB interface, hydraulic calculation, vectorized model changes, steady water quality, hydraulic sensitivities and diameter optimization.

All examples use SI units at their public interfaces.
